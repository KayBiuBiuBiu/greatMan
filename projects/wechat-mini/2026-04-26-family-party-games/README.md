# 家庭聚会助手（微信小程序）

一个原生微信小程序项目，用页面组件实现家庭/亲友**线下同场**聚会、亲子互动和趣味辅助工具（无陌生匹配、无广域竞技表述）。

当前主入口是 `app.js` 和 `app.json`，`project.config.json` 已设置为：

```json
{
  "compileType": "miniprogram",
  "appid": "wxce58d943a0f4a80e"
}
```

## 已实现功能

- 面对面私密口令聚会组
  - 主持选择互动后创建 4 位口令聚会组
  - 身边参与者输入同一口令加入
  - 组内展示参与者列表与主持标识
  - 主持点击开始后，其他人同步进入同一互动页
- A类：谁是卧底
  - 4-12 人选择
  - 1-2 名不同词随机分配
  - 内置词对
  - 逐个展示词语
  - 投票、最高票暂离、记录
  - 本环节收束说明（非广域排名）
- A类：真心话大冒险
  - 真心话、趣味任务双题库
  - 随机抽题和下一题
  - 简易参与者次数记录
- B类：你画我猜轮流传词版
  - 随机词库
  - 隐藏/展示词语
  - 传给下一人
  - A 队、B 队、自由局计分
- C类：故事接龙
  - 随机故事开头
  - 记录接龙句数
  - 生成全文预览
- C类：逛三园
  - 随机主题
  - 示例词提示
  - 5 秒计时提醒
  - 失败者惩罚次数记录

首页列出 A、B、C 各类**聚会玩法/辅助工具**，均可进入对应页面使用。

## 运行方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `projects/wechat-mini/2026-04-26-family-party-games`。
4. 确认项目类型为“小程序”，AppID 为 `wxce58d943a0f4a80e`。
5. 在微信开发者工具中开通云开发，并部署 `cloudfunctions/roomService`。
6. 点击“编译”运行。
