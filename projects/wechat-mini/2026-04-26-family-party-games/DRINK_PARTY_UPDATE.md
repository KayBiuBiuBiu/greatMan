# 趣味抽签游戏更新说明

## 更新内容

### 1. 移除用户列表背景闪烁效果
**原因**：倒计时阶段的背景闪烁容易让用户眼花

**改动**：
- 移除了原有的 `dp-member-pulse` 动画（背景色从白色闪烁到橙色）
- 改为简单的透明度变化：`opacity: 0.75`，配合淡色背景 `rgba(0, 0, 0, 0.02)`
- 移除了 `memberPulseDuration` 的动态计算逻辑

**相关文件**：
- `drink-party.js`：移除 `_memberPulseDurationMs()` 调用
- `drink-party.wxml`：移除 `dp-member-pulse` 类和动画持续时间样式
- `drink-party.wxss`：简化动画为单纯的透明度变化

---

### 2. 抽签结果改为弹窗转盘选择
**原因**：原来直接显示"喝N口"太单调，改为趣味转盘让用户选择不同的喝酒方式

**改动**：
用户被抽中后，不再直接显示"喝X口饮料"，而是弹出一个**转盘弹窗**，显示5个抽奖选项：

1. **自己喝 1-10 口** — 被抽中的人自己喝
2. **左右两边各喝 1-10 口** — 两侧各喝一人
3. **喂异性喝 1-10 口** — 指定异性喝
4. **指定一人喝 1-10 口** — 随意指定任意人
5. **除了自己其余都喝** — 全员都喝（被抽中的人除外）

**用户交互**：
- 打开弹窗后，用户可以点击转盘开始旋转
- 转盘会依次循环显示各个选项
- 点击"确认"按钮锁定最终选择

**相关文件**：
- `drink-party.js`：
  - 新增 `_openRouletteModal()` 方法
  - 新增 `_startRouletteAnimation()` 方法
  - 修改 `_playRingAlert()` 触发转盘而不是直接显示结果
  - 新增 `onRouletteTap()`、`onRouletteClose()`、`onRouletteConfirm()` 事件处理
- `drink-party.wxml`：新增转盘UI模板
- `drink-party.wxss`：新增转盘样式

---

### 3. 转盘动画优化 - 越来越慢然后停顿
**原理**：
- 初始动画速度快（30ms 刷新一次）
- 逐渐减速（每次延迟增加 15ms）
- 最终停止在某个选项上

**动画参数**：
```javascript
// 快速阶段：前 12 次迭代，30ms 一次刷新
// 减速阶段：第 12～28 次迭代，延迟从 30ms → 400ms
// 停止：第 28 次迭代后停止
nextDelay = Math.min(400, 30 + (iteration - 12) * 15)
```

**效果**：
- 开始时快速转动，营造紧张感
- 逐渐减速，暗示即将停止
- 最后停在某个选项上，用户可以确认选择

**相关代码**：
- `_startRouletteAnimation()` 中的递归 `setTimeout` 实现渐进式减速
- `drink-party.wxss` 中的 `@keyframes dp-pulse-item` 为选中项的脉冲动画
