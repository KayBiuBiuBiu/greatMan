# 趣味抽签游戏更新说明

## 更新内容

### 1. 移除用户列表背景闪烁效果
**原因**：倒计时阶段的背景闪烁容易让用户眼花

**改动**：
- 移除了原有的 `dp-member-pulse` 动画（背景色从白色闪烁到橙色）
- 改为简单的透明度变化：`opacity: 0.75`，配合淡色背景 `rgba(0, 0, 0, 0.02)`
- 移除了 `memberPulseDuration` 的动态计算逻辑

**相关文件**：
- `drink-party.js`：移除 `_memberPulseDurationMs()` 调用
- `drink-party.wxml`：移除 `dp-member-pulse` 类和动画持续时间样式
- `drink-party.wxss`：简化动画为单纯的透明度变化

---

### 2. 抽签结果改为文字上下滚动
**原因**：不用圆盘，改为简洁的文字上下滚动效果

**改动**：
用户被抽中后，弹出文字滚动弹窗，显示5个抽奖选项上下滚动：

1. **自己喝 1-10 口** — 被抽中的人自己喝
2. **左右两边各喝 1-10 口** — 两侧各喝一人
3. **喂异性喝 1-10 口** — 指定异性喝
4. **指定一人喝 1-10 口** — 随意指定任意人
5. **除了自己其余都喝** — 全员都喝（被抽中的人除外）

**用户交互**：
- 弹窗打开后，文字自动开始滚动
- 用户也可点击「开始转」重新转盘
- 等待滚动停止或手动停止后，点「确认」锁定选择

**相关文件**：
- `drink-party.js`：
  - 新增 `_openLotteryScroll()` 方法
  - 新增 `_startLotteryScroll()` 方法
  - 修改 `_playRingAlert()` 触发文字滚动
  - 新增 `onLotteryScroll()`、`onLotteryClose()`、`onLotteryConfirm()` 事件处理
- `drink-party.wxml`：新增滚动UI模板
- `drink-party.wxss`：新增滚动样式

---

### 3. 文字滚动动画优化 - 越来越慢然后停顿
**原理**：
- 初始动画速度快（50ms 刷新一次）
- 逐渐减速（每次延迟增加 20ms）
- 最终停止在某个选项上

**动画参数**：
```javascript
// 快速阶段：前 10 次迭代，50ms 一次刷新
// 减速阶段：第 10～30 次迭代，延迟从 50ms → 500ms
// 停止：第 30 次迭代后停止
nextDelay = Math.min(500, 50 + (iteration - 10) * 20)
```

**效果**：
- 开始时快速滚动，营造紧张感
- 逐渐减速，暗示即将停止
- 最后停在某个选项上，用户可以确认选择

**相关代码**：
- `_startLotteryScroll()` 中的递归 `setTimeout` 实现渐进式减速
- `drink-party.wxss` 中的 `@keyframes dp-lottery-highlight` 为选中项的脉冲动画

## UI 效果说明

### 文字滚动框的样式：
- **背景**：渐变色（#fff5e6 到 #fff9f0）
- **边框**：品牌色橙色，3rpx 粗
- **选中项**：
  - 文字放大到 1.15 倍
  - 品牌色橙色文字
  - 轻微背景高亮
  - 脉冲动画效果

### 指示器：
- 中间有一条横线，标识选中项的位置

### 按钮：
- **取消**：灰色按钮
- **开始转**：橙色渐变按钮（动画中禁用）
- **确认**：橙色渐变按钮（动画中禁用）
