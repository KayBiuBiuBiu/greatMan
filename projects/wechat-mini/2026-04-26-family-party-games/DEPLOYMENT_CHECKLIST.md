## 📦 第三步：创建数据库集合 [待手动操作]

### 集合 1: gesture_rooms

```
集合名: gesture_rooms
权限: ADMINONLY (仅管理员)
```

**创建步骤:**
1. 云开发 → 数据库 → 创建集合
2. 集合名输入 `gesture_rooms`
3. 权限选择 ADMINONLY
4. 创建索引:
   - 字段: `roomCode`
   - 类型: 唯一

**必要字段:**
| 字段 | 类型 | 说明 |
|------|------|------|
| roomCode | string | 6位口令 |
| hostOpenId | string | 房主 |
| status | string | 房间状态 |
| totalRounds | number | 总轮数 |
| currentWordText | string | 当前词语 |

### 集合 2: gesture_players

```
集合名: gesture_players
权限: ADMINONLY
```

**创建步骤:**
1. 云开发 → 数据库 → 创建集合
2. 集合名输入 `gesture_players`
3. 权限选择 ADMINONLY
4. 创建索引:
   - 字段组合: `roomId` + `openId`
   - 类型: 复合唯一

**必要字段:**
| 字段 | 类型 | 说明 |
|------|------|------|
| roomId | string | 房间ID |
| openId | string | 玩家OpenID |
| nickName | string | 昵称 |
| score | number | 得分 |

### 集合 3: gesture_gameState

```
集合名: gesture_gameState
权限: 登录用户可读，仅云函数可写
```

**创建步骤:**
1. 云开发 → 数据库 → 创建集合
2. 集合名输入 `gesture_gameState`
3. 权限设置:
   - 读: 登录用户可读
   - 写: 仅云函数可写
4. 无需创建索引

**必要字段:**
| 字段 | 类型 | 说明 |
|------|------|------|
| _id | string | = roomId |
| phase | string | 游戏阶段 |
| currentRound | number | 当前轮数 |
| performerOpenId | string | 表演者 |
| publicPlayers | array | 排行榜 |
| roundHits | array | 答对者 |

### 验证创建

## 📞 遇到问题？

### 常见问题排查

**问题 1: 云函数部署失败**
- 检查 `package.json` 是否存在
- 确认「云端安装依赖」已勾选
- 检查网络连接

**问题 2: 数据库集合创建失败**
- 确认索引类型正确（唯一/复合唯一）
- 检查集合名称拼写
- 验证权限设置

**问题 3: 编译错误**
- 点击「清除缓存」重新编译
- 检查 `app.json` 中的页面路径
- 验证所有导入的文件存在

**问题 4: 游戏无法创建房间**
- 检查云函数是否部署成功
- 查看开发者工具控制台错误
- 验证数据库集合权限

**问题 5: 多人无法同步**
- 检查两台设备是否连同一WiFi
- 验证 `gesture_gameState` 权限正确
- 查看云函数日志
