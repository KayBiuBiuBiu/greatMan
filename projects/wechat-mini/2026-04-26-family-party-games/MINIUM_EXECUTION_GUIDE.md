## 排查流程

### 常见问题 1: Minium 连接超时

**症状**:
```
ConnectionRefusedError: Failed to connect to http://localhost:9420
```

**排查步骤**:
1. 确认微信开发者工具已打开
2. 确认项目已正确加载
3. 确认「自动化测试」模式已启用
   - 右上角 ⋮ → 自动化测试 → 本地自动化
4. 检查端口 9420 是否被占用
   ```bash
   lsof -i :9420
   ```
5. 重启微信开发者工具

### 常见问题 2: 找不到游戏卡片

**症状**:
```
NoSuchElementException: //view[contains(text(), '你比划我猜')]
```

**排查步骤**:
1. 确认小程序已编译 (Ctrl/Cmd + B)
2. 确认游戏已添加到首页
   - 检查 `data/game-data.js` 是否包含「你比划我猜」
3. 手动进入小程序验证游戏卡片是否可见
4. 在开发者工具中检查 DOM 结构是否变化

### 常见问题 3: 云函数调用失败

**症状**:
```
Cloud function call failed: gestureRoomService not deployed
```

**排查步骤**:
1. 确认 `gestureRoomService` 已部署
   - 云开发 → 云函数 → 确认绿色显示
2. 查看云函数日志
   - 云开发 → 日志
3. 检查数据库集合是否创建
4. 检查网络连接

### 常见问题 4: 数据库权限错误

**症状**:
```
Error: Permission denied for collection gesture_rooms
```

**排查步骤**:
1. 确认集合存在
   - 云开发 → 数据库
2. 检查集合权限设置
   - gesture_rooms: ADMINONLY (仅云函数写)
   - gesture_gameState: 登录用户可读，仅云函数可写
3. 查看详细错误日志

### 常见问题 5: 测试超时

**症状**:
```
Test timeout after 30000ms
```

**排查步骤**:
1. 检查网络连接速度
2. 检查小程序是否卡顿
3. 增加超时时间 (编辑脚本)
4. 重启微信开发者工具
