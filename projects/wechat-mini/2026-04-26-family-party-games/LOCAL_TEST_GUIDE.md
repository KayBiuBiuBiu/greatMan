## 🎯 快速开始

你现在已经有了完整的测试脚本，可以在本地直接运行！

### 步骤 1: 准备环境（本地电脑）

```bash
# 确保 Minium 已安装
pip install minium

# 进入项目目录
cd /Users/haha/greatMan/projects/wechat-mini/2026-04-26-family-party-games
```

### 步骤 2: 启动微信开发者工具

1. 打开微信开发者工具
2. 选择项目: `/Users/haha/greatMan/projects/wechat-mini/2026-04-26-family-party-games`
3. 点击编译: `Ctrl/Cmd + B`
4. 启用自动化调试: 右上角 ⋮ → 自动化测试 → 本地自动化

### 步骤 3: 运行测试

```bash
# 方式 1: 使用启动脚本 (推荐)
bash run_test_local.sh

# 方式 2: 直接运行 Python
python tests/test_gesture_final.py
```

### ❌ 常见问题

**Q: 连接被拒绝 (Connection refused)**
- A: 检查微信开发者工具是否打开，自动化调试是否启用

**Q: 找不到游戏卡片**
- A: 确认小程序已编译，游戏卡片在 B 类区块中

**Q: 云函数调用失败**
- A: 检查 gestureRoomService 是否已部署（应显示绿色）

**Q: 数据库错误**
- A: 检查三个集合是否都已创建，权限是否正确
