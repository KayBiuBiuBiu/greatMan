2.2 十阶段逐帧精细化开发步骤（全流程无遗漏）

阶段1：waiting 等待开局（初始状态）

阶段定位：聚会组创建后初始状态，用于等待成员加入、配置难度、准备开局

- 权限规则：所有进入房间玩家仅可查看，仅组长拥有操作权限

- 前端固定展示内容：6位聚会组口令、在线成员列表、难度选择器、「开始互动」按钮

- 组长精准操作步骤：
  

  1. 确认在线成员人数≥3人

  2. 选择本局游戏难度（新手/进阶/烧脑）

  3. 点击「开始互动」按钮触发云函数startGame

- 兜底校验：成员人数不足3人，弹出固定提示「至少3人才能开始互动」，禁止进入下一阶段

- 阶段结束条件：组长成功触发开局，服务端校验通过跳转至generate_script

阶段2：generate_script AI生成剧本（纯服务端静默阶段）

阶段定位：全自动后台生成本局所有游戏数据，无玩家操作，瞬时完成

- 触发时机：组长点击开始互动、人数校验通过后立即自动执行

- 服务端精准执行步骤：
  

  1. 读取当前聚会组：人数、选定难度、组长信息

  2. AI随机抽取本局结局模式（4种结局纯随机，无规律、无前置提示）

  3. 批量生成本局核心数据：全员独立人设、单人专属剧本、个人作案时间线、个人隐藏秘密、个人嫌疑标签、全局案件背景

  4. 初始化空数据：空证据池、空投票记录、空证据派发记录、未解锁复盘状态

  5. 自动推送阶段跳转，进入读本阶段

- 前端固定表现：全屏加载态，展示文案「AI正在生成专属剧本，请稍候」，禁止任何用户操作

- 阶段特性：无倒计时、无手动干预、纯服务端自动流转

阶段3：read_script 读本阶段（300s）

阶段定位：玩家阅读专属个人剧本、熟悉身份与背景，线下默默熟悉人设

- 玩家权限&操作：仅可打开、查看、反复回看个人剧本，无任何提交、编辑、输入操作

- 前端固定元素：阶段倒计时、剧本阅读弹窗、全员就绪按钮

- 阶段结束三种触发条件（满足任一即跳转）：


  1. 300s倒计时自动结束

  2. 所有玩家手动点击「就绪」

  3. 组长手动点击跳过阶段

- 核心强制规则：个人剧本属于私密数据，仅本地存储、仅本机可见，不上传服务端、不同步其他玩家，杜绝身份泄露

阶段4：public_discuss 公聊推理阶段（1200s）

阶段定位：线下玩家面对面语音交流、自我介绍、对时间线、互相盘问，全程纯口语互动

- 玩家交互规则：全程零打字、零文字交流，所有推理、盘问、辩解均为线下面对面语音完成

- AI辅助逻辑：检测玩家长时间冷场时，推送轻度公共推理提示，绝不剧透凶手、不泄露结局

- 组长权限：可随时手动提前结束本阶段，进入证据派发阶段

- 阶段核心作用：让玩家互相熟悉身份、梳理时间线、制造初步嫌疑矛盾，为后续证据博弈铺垫

2.3 三轮证据AI精准配比规则（对接AI Prompt唯一标准）

所有证据配比严格按以下规则生成，保证每局推理平衡、有悬念、无碾压、无白给

- 第一轮证据（全员公共、无实锤）

  - 内容范围：案发现场环境细节、全员公共在场记录、基础时间线物证

  - 属性：100%无实锤，无指向性凶手线索

  - 作用：消除全员绝对清白，让所有玩家均带有轻微嫌疑，制造全员博弈氛围

- 第二轮证据（公私结合、核心错觉体系）

  - 公共部分：人物过往恩怨、团队公共矛盾、集体不在场证明

  - 私密个人证据（千人千面独立生成）：
    

    - 清白玩家/NPC凶局：70%嫌疑误导伪证据 + 30%自我洗白真证据

    - 真凶/共犯玩家：70%洗白误导伪证据 + 30%微量疑点真证据

- 第三轮证据（关键锁线、真假对半博弈）

  - 内容范围：核心作案痕迹、人物隐藏关系、证词矛盾点、排他性关键线索

  - 配比规则：50%真实定罪证据 + 50%高阶误导伪证据

  - 作用：提供充足辩论空间，供玩家线下口头拆解真伪、串联完整证据链

2.4 证据体系兜底强制逻辑（必须完整开发）

- 阶段提前结束兜底：组长手动提前结束阶段时，系统自动补全所有未派发轮次证据，保证线索不缺失、对局完整性不受影响

- 断线重连兜底：公共证据从服务端实时同步，个人私密证据本地缓存恢复，断网重连无数据丢失

- 幂等防重复兜底：每一轮证据仅生成、派发一次，永久不会重复追加、覆盖错乱

阶段6：analyze_clue 线索剖析辩论阶段（900s）

阶段定位：全局核心辩论博弈阶段，玩家线下口头拆解所有证据真伪、互相对质洗白

- 玩家行为：基于三轮全部证据，面对面语音对质、拆穿伪证据、梳理真实线索、串联案件真相

- AI辅助能力：自动识别全场证据矛盾点，推送精准推理方向提示，不直接剧透答案

- 阶段规则：无任何新证据派发，仅做线索复盘、博弈、辩论

- 组长权限：可手动提前结束阶段，进入最终投票环节

阶段7：final_vote 最终投票阶段（300s）

阶段定位：全员锁定嫌疑人，完成本局最终推理判定

- 投票可选范围：所有在线在场玩家 + 本局全部公开NPC嫌疑人

- 投票规则：支持重复改票，后一次投票数据自动覆盖前一次记录

- 防刷规则：云函数幂等拦截无效重复投票，杜绝恶意刷票、重复提交

- 结算规则：300s倒计时结束，服务端自动统计票数、锁定最终投票结果，自动进入下一阶段

阶段8：wait_unlock_review 锁定结局等待解锁

阶段定位：保护结局保密性，防止提前剧透

- 保密规则：本局所有结局、复盘、真相内容完全隐藏，前端无任何预览、无任何入口、无任何缓存泄露

- 解锁唯一条件：聚会组内任意一名玩家完成微信合法分享验证

- 权益规则：单人操作、全员受益，一人解锁后所有玩家同步查看完整结局复盘

阶段9：ai_review AI全自动复盘展示

阶段定位：本局对局完整总结，揭晓全部真相

- 触发逻辑：分享验证通过后，服务端立即自动生成完整复盘内容

- 复盘固定必填模块（缺一不可）：
  

  1. 本局结局定性判定

  2. 完整闭环作案链条还原

  3. 全员个人疑点逐一拆解

  4. 所有伪证据误导原理说明

  5. 全员个人隐藏秘密解密

  6. 玩家本局推理表现点评

  7. 平票场景专项分析兜底内容

阶段10：finished 对局彻底结束

阶段定位：本局收尾，支持新一轮对局重启

- 页面展示：完整结局 + 全部复盘内容永久展示

- 操作权限：仅组长可见「重启对局」按钮，普通玩家无重启权限

- 重启逻辑：点击后清空本局所有数据、重置所有状态，直接回归waiting初始状态，可开启新一局游戏

5.1 submitVote 投票幂等

// 1. 阶段合法性校验
if (room.phase !== "final_vote") {
  return { success: false, msg: "当前非投票阶段" }
}
// 2. 幂等拦截：同目标重复投票直接返回成功，禁止重复写入
const prev = room.voteRecord[openId]
if (prev === targetId) {
  return { success: true, msg: "投票成功", data: room.voteRecord }
}
// 3. 改票：不同目标允许覆盖；数据库事务原子写入
await db.runTransaction(async (transaction) => {
  await transaction.collection("mystery_reason_rooms").doc(roomId).update({
    data: { [`voteRecord.${openId}`]: targetId, updateTime: Date.now() }
  })
})
return { success: true, msg: "投票成功" }


5.2 refreshEvidence 证据派发幂等

// 1. 阶段锁定校验
if (room.phase !== "get_evidence") {
  return { success: false, msg: "当前阶段无法刷新证据" }
}
// 2. 轮次幂等拦截：已生成过则直接返回现有数据，杜绝重复生成
const { round } = params
const finishedRounds = room.evidenceRoundRecord || []
if (finishedRounds.includes(round)) {
  return { success: true, data: { publicClue: room.publicClue, playerEvidence: room.playerEvidence } }
}
// 3. AI生成全新证据并原子入库
const newEvidence = await aiGenerateEvidence(room, round)
await db.collection("mystery_reason_rooms").doc(roomId).update({
  publicClue: newEvidence.publicClue,
  playerEvidence: newEvidence.playerEvidence,
  evidenceRoundRecord: [...finishedRounds, round]
})
return { success: true, data: newEvidence }

// 1. 全局幂等拦截：已解锁直接返回复盘内容
if (room.reviewUnlocked === true) {

// 300ms全局防抖，防止重复点击、重复请求
export function debounce(fn, delay = 300) {
  let timer = null
  return function(...args) {
    if (timer) return
    timer = setTimeout(() => {
      fn.apply(this, args)
      timer = null
    }, delay)
  }
}
// 所有提交类按钮统一封装调用
export const actionDebounce = debounce(async (fn) => {
  await fn()
})
