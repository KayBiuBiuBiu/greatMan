## 如何使用本文档

| 标记 | 含义 |
|------|------|
| **云同场** | 6 位数字口令，状态在云端，多人手机同步 |
| **本地辅助** | 主要靠 `play` 页随机题/计时/计分，线下口头玩 |
| **4 位口令** | 旧版 `roomService`，仅真心话大冒险同场投票等 |

## 一、产品总览

### 1.1 两套「进组」体系（最容易混）

| | 6 位口令 | 4 位口令 |
|---|----------|----------|
| 用途 | 卧底、身份推理、画猜、猜歌、趣味抽签 | 真心话大冒险「同场投票」、部分本地游戏建房记录 |
| 云函数 | 各自独立 `*RoomService` | `roomService` → `rooms` |
| 首页「输入口令」 | 依次尝试 5 个 6 位服务 | 仅当输入 4 位时走 `roomService` |

**6 位是房号，不是最少人数。**

### 1.2 三类实现

```
首页点「开始互动」
  ├─ screen = werewolf / undercover / songGuess / drawGuess / drinkParty
  │     → setup 创建 6 位云聚会组 → 对应专页
  └─ screen = play（其余游戏名）
        → setup 可选 4 位口令 → play 页本地辅助
```

### 1.3 通用规则（所有云同场）

- **组长**：创建聚会组的人（`hostOpenId`），多数「开始」按钮仅组长可点。
- **开始前校验**：`runStartAction` 先查人数/权限/阶段，再调云函数。
- **同步**：进房后云函数 **`syncState` 每秒轮询**（公屏 + 本人视角），`watch` 作加速；参与者勿依赖直连读 `*_gameState`（库权限常不足）。趣味抽签、猜歌、真心话大冒险（4 位 `roomService`）、卧底、身份推理、画猜均已接入；**分享/深链进房须先 `join`**（`enterCloudRoomOnLoad`），未在房时 `syncState` 返回 `inRoom:false` 会自动补 join。
- **首页开放**：仅 **趣味抽签、疯狂猜歌、真心话大冒险** 可点「开始互动」；其余卡片置灰并显示「正在开发中」（`data/feature-flags.js` → `HOME_ENABLED_TITLES`）。
- **无广域匹配**：只能亲友传口令，不能随机匹配陌生人。

## 二、云同场游戏（6 位口令）

### 2.1 趣味抽签 `drinkParty`

**页面**：`pages/drink-party/drink-party`  
**云函数**：`drinkRoomService`  
**最少人数**：≥ 2（组长点「开始本轮」）

#### 阶段状态机

```
waiting（等人）
    ↓ 组长 startRound
countdown（约 3 秒，无 321 界面）
    ↓ 任意在组的人 revealRinger（Go 后客户端自动调）
result（随机响铃者 + 喝 1～10 口）
    ↓ 组长 nextRound
waiting
```

#### 实际玩法（按代码）

1. **抽签等待**：进入 `countdown` 约 3 秒（**不显示 321 窗口**，仅状态条「抽签中」）。
2. **响铃 + 口数**：结束后云端**随机选 1 人**，随机 `drinkSips`（1～10），进入 `result`；**仅被抽中者本机**播放 `ring.mp3`、强震、闪屏。
3. **全员看文案**：结果页大字「张三 喝 5 口饮料」；响铃者另有 Toast「你的手机响了！喝 5 口饮料」。

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 所有人一起震、一起响 | **只有被抽中 1 人**在倒计时结束后响铃；321 仅数字 |
| 还要投票指认 | 已去掉投票，Go 后直接出结果 |
| 模拟器能震能响 | 需真机；模拟器常无震无声 |

### 2.2 谁是卧底 `undercover`

**页面**：`pages/undercover/undercover`  
**云函数**：`undercoverRoomService`  
**最少人数**：≥ 3，且 **当前人数 = 组长设定人数**（4～12）才能发牌

#### 流程摘要

```
waiting → 组长 startGame（发词）
word（每人本机看词，可 ackWord）
discuss（按 speakOrder 轮流发言，组长 hostNextSpeak）
vote → 可能 vote_tie（平票再投）
出局判定 → 可能下一讨论轮或 ended（平民胜/卧底胜）
```

- **1 个卧底**，其余平民；词对来自内置库 / 组长自定义 / AI 生成。
- **词只存在玩家文档**，公屏 `uc_state` **不含词面**。
- 胜负：出局者是卧底 → 平民胜；剩 2 人且仍有卧底 → 卧底胜。

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 满 3 人就能开 | 必须 **凑满设定人数**（如设 6 人就要 6 人到齐） |
| 和旧版 4 位 `rooms` 互通 | **完全隔离**，6 位专用 v2 |

### 2.3 秘密身份推理（聚会版）`werewolf`

**页面**：`pages/werewolf/werewolf`  
**云函数**：`werewolfService`  
**板子**：6 / 8 / 10 / 12 人固定身份分配

#### 流程摘要

- **非自动法官**：组长（主持）手动推进夜晚/白天（`hostResolveNight`、`hostDawnToSpeak`、`hostStartVote` 等）。
- 狼人/预言家/女巫等 **仅本机** 看到自己的操作按钮；身份不公屏。
- 阶段：`lobby` → `night` → `day_announce` → `speak` → `vote` → … → `end`。

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 人齐就能自动开局 | 须组长 `start`，且人数 **等于板子人数** |
| 全自动狼人杀法官 | **主持驱动**，依赖组长点流程 |

### 2.4 你画我猜（同场画布）`drawGuess`

**页面**：`pages/draw-guess/draw-guess`  
**云函数**：`drawRoomService`  
**首页状态**：**已关闭**（`data/feature-flags.js` → `DRAW_GUESS_ENABLED = false`）

#### 若重新打开后的实际逻辑

```
waiting → 组长 startGame（选词、定画家）
drawing → 画家抬笔时全量上传笔画（updateCanvas）；猜词者看画板猜
revealed → 揭晓答案与得分
nextRound / finished
```

- 词语 **仅画家** 在 `getView.painterWord` 可见，公屏不含词面。
- 画板固定 **280×400**，画家沉浸模式；猜词端有笔迹后才显示画板（曾改过多版，以代码为准）。
- **未使用** 增量 `appendStroke`（当前为抬笔全量同步）。

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 首页「你画我猜轮流传词版」= 云画布 | 首页名是「轮流传词版」；云画布是 `drawGuess` 入口（**现已关闭**） |
| `play` 里你画我猜 = 同房云画 | `play` 模式 `draw` 是 **本地随机一个词**，无云同步 |

### 2.5 疯狂猜歌 `songGuess`

**页面**：`pages/song-guess/song-guess`  
**云函数**：`musicRoomService`  
**最少人数**：≥ 2

#### 实际机制

- **组长（房主）**固定为当轮主持（`roundHostOpenId` = `hostOpenId`），在其手机上看歌名。
- **小程序不统一播歌**；由主持 **本机外放**（哼唱/播放音乐 App），其他人听声音猜。
- 主持 **不能提交答案**；其他人输入歌名，`submitAnswer` 匹配曲库 `title` / `aliases`。
- 无单首倒计时，由组长点「下一题」推进；轮数 5/10/15 可选。

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 小程序会播放歌曲 | **不会**，只显示歌名给主持 |
| 所有人都能猜 | **当轮主持不能猜** |

### 2.6 真心话大冒险 · 同场（4 位口令）

**页面**：`pages/play/play`，`mode: truthDareRoom`  
**云函数**：`roomService`（`rooms`，约 4 小时 TTL）  
**口令**：**4 位**（不是 6 位）

#### 流程

```
tdStart → 随机「被选中人」targetOpenId，phase: voting
其他人 tdVote：truth 或 dare（被选中人不能投）
主持 tdTally → 计票；平票有隐藏彩蛋文案
胜方类型确定后，被选中人本机抽 truthQuestions / dareQuestions 展示
主持再 tdStart 下一轮
```

#### 容易误解

| 你以为 | 实际 |
|--------|------|
| 和 6 位趣味抽签一样 | **4 位 + roomService**，数据不互通 |
| 首页「真心话大冒险」一定同房 | 也可走 **本地模式** `truthDare`，无云投票 |

## 三、本地辅助游戏（`pages/play/play`）

**数据**：`data/game-data.js` → `helperGames` + 题库常量  
**入口**：首页 → 开始互动 → `setup`（可生成 4 位口令分享）→ `play?title=游戏名`

**共性**：主持人拿一台手机看题/计时/计分，**亲友主要口头互动**；除真心话 4 位同房外，**无实时状态同步**。

### 3.1 游戏列表与模式

| 游戏名 | mode | 小程序实际做什么 |
|--------|------|------------------|
| 真心话大冒险 | `truthDare` | 本地随机真心话/大冒险题库，换题 |
| 海龟汤 | `riddle` | 换汤面、看汤底、提示 |
| 优点轰炸 | `promptScore` | 换夸夸提示，手动 +1 分 |
| 大瞎话 | `random` | 随机搞怪任务 |
| 猜数字 | `number` | 1～100 随机数，主持人输入猜测给大小提示 |
| 十五二十 | `score` | 双人计分板 |
| 疯狂猜歌（线下版） | `randomScore` | 随机歌名**文字提示**，主持人口头哼；猜中 +1 |
| 倒着说 | `reverse` | 短句倒序挑战，答对 +1 |
| 默契大考验 | `promptScore` | 换问题，主持人记是否多人指同一人 |
| 123木头人/红绿灯 | `traffic` | 随机绿灯/红灯/木头人口令，暂离 +1 |
| 网鱼 | `ruleRandom` | 随机几人当「网」的规则说明 |
| 画一画长卷 | `timerRandom` | 换主题 + 计时 |
| 成语接龙/飞花令 | `wordRecord` | 换起点字 + 记录 |
| 蒙眼贴五官 | `timerRandom` | 换难度 + 计时 |
| 躲猫猫/找影子 | `random` | 手影/规则挑战文案 |
| 揪尾巴 | `score` | 计分说明 |
| 袋鼠跳跳跳 | `stopwatch` | 秒表 |
| 爱心接力/齐心协力 | `timerRandom` | 随机协作任务 + 计时 |
| 我是影帝 | `randomScore` | 随机表演场景，猜中 +1 |
| **你画我猜（传词版）** | `draw` | **仅随机一个词**（`drawWords`），给表演者看，**无画板** |
| 故事接龙 | `story` | 随机开头 + 本地接句列表 |
| 逛三园 | `garden` | 随机「XX园」+ 示例词，5 秒倒计时 |

### 3.2 容易误解（本地类）

| 你以为 | 实际 |
|--------|------|
| 逛三园会自动判词重复 | **只提供园名、示例和 5 秒计时**，重复与否靠人判 |
| 猜数字多人各自输入 | **主持人输入**他人猜测，屏幕给大了/小了 |
| 本地疯狂猜歌会播放 | 同云版，**只有文字歌名提示** |

## 六、功能开关与已知问题（梳理用）

| 项 | 状态 | 说明 |
|----|------|------|
| 你画我猜云版 | `DRAW_GUESS_ENABLED = false` | 改 `data/feature-flags.js` 为 `true` 并重新编译可恢复 |

| 画猜笔画同步 | 抬笔全量 | 非实时每笔上传 |
| AI 功能 | 多页可选 | 需云开发 + 部分玩法需分享解锁 |

## 七、建议你重点核对的逻辑点

若你觉得「玩法不对」，可逐项对照：

1. **趣味抽签**：口数文案为「喝 X 口饮料」，仅作聚会互动提示，请自行把握饮酒量。  
2. **卧底/狼人**：是否接受「必须满员才能开始」？  
3. **猜歌**：是否接受「主持手机外放、小程序不播歌」？  
4. **你画我猜**：要开云版还是只要本地看词？（当前云版关）  
5. **真心话**：要 4 位同房投票，还是单机抽题？  
6. **本地辅助类**：是否误当成会自动判胜负/同步的多人游戏？
