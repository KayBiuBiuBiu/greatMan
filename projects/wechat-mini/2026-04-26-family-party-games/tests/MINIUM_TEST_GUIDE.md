## 常见问题排查

### 问题 1：房间创建失败

**症状**：点击「创建聚会组」后无反应或报错

**排查步骤**：
```
1. 检查云开发是否开通
   → 微信开发者工具 → 云开发 → 检查环境是否绿色
   
2. 检查云函数是否部署
   → cloudfunctions/gestureRoomService → 确认已部署
   
3. 查看云函数日志
   → 云开发 → 日志 → 搜索 gestureRoomService
   
4. 重新编译
   → Ctrl/Cmd + B
```

### 问题 2：加入房间失败

**症状**：输入口令后无法加入

**排查步骤**：
```
1. 确认口令正确（6 位数字）
2. 确认房间未过期（创建后 4 小时内）
3. 确认人数未超过限制（最多 20 人）
4. 查看网络连接
```

### 问题 3：答题无反应

**症状**：点击「提交答案」无反应

**排查步骤**：
```
1. 确认当前为猜词者（不是表演者）
2. 确认答案框不为空
3. 查看倒计时是否超时
4. 检查网络连接
```

### 问题 4：分数未更新

**症状**：答对但分数没有增加

**排查步骤**：
```
1. 确认答案完全匹配（不区分大小写）
2. 查看排行榜是否更新
3. 检查云函数日志中 submitGuess 的返回值
```
