本节记录 **已实现项**、**依赖外部数据/后续再接**项，便于排期。

## 已实现（代码与本仓库）

| 优先级 | 项 | 说明 |
|--------|----|------|
| P0 | **小样本训练** | `ops_automation.ml_train_min_samples` 默认 18、下限 6；`incremental_nb_min_samples` 默认 12、下限 6；`ml_train.py` / `ml_nb_incremental.py` CLI 默认值已下调。**仍需库里有已打标的 0/1 两类样本**，否则仍会跳过训练。 |
| P1 | **启动配置自检** | `merge_full_config` 后继续保留 JSON Schema；`run_alert.py` 启动时执行 **`config_startup_check`**（`--skip-startup-check` 可跳过）；`python run_alert.py -c config.json --verify-config` 仅自检后退出。 |
| P2 | **数据源心跳文件** | `data_health.heartbeat_path` + `heartbeat_interval_sec`（秒，≥30）：每轮轮询末尾写入 **JSON**，含时间戳、`watch_count`、本轮 `attempted`/`fails`、`degraded_hosts` 摘要。 |

| P2 | **launchd 保活示例** | 见 **`macos/launchd-stock-price-alert.plist.example`** 与 **`macos/README-launchd.md`**（需自行替换路径后 `launchctl load`）。 |
| — | **config 启动备份** | 每次正常合并配置后（**非** `--verify-config`），将 `-c` 指向的文件复制为同目录 **`config.json.bak`**（与 auto_tune 等备份无关，已加入 `.gitignore`）。 |
| — | **行业缓存目录自检** | `config_startup_check` 对 **`sector_index_cache.json` 所在目录** 做 probe 写入，并检查已存在文件的 `W_OK`。 |

### NB 训练（仅真实 `hit`）

`ml_train.py` 只从 `alert_events` 读取 **`hit` 为 0 或 1** 的 `trend_slip` / `drawdown` 样本。请先跑 `backtest_alerts.py` 补 `hit`，再执行：

```bash
python ml_train.py -c config.json
```

（可按样本量降低 `--min-samples`，须仍含 0、1 两类。）

## 快速自检命令

