## 🔧 三处改造位置

**文件**：`run_alert.py` 第 ~8700 行的 `main()` 函数

```python
from display_with_us_context import show_us_context_banner

def main() -> int:
    # ... 配置加载、解析参数等 ...
    
    print(show_us_context_banner())  # ← 加这一行
    
    # ... 继续轮询 ...
```

---

### 改造 2：选股输出加美股标签（8 行代码）

**文件**：`quant_cli.py` 或 `run_alert.py` 的日报输出

```python
from display_with_us_context import format_us_context_inline

# 输出选股结果时：
for pick in quality_picks:
    us_tag = format_us_context_inline(pick['code'], pick.get('industry', ''))
    print(
        f"  {pick['code']} {pick['name']:12} "
        f"分数 {pick['score']:.1f} {us_tag}"
    )
```

---

### 改造 3：监控显示加美股参考（5 行代码）

**文件**：`run_alert.py` 的 watch_pack 输出逻辑

```python
from display_with_us_context import format_us_context_inline

for code in watch_codes:
    quote = get_live_quote(code)
    us_ref = format_us_context_inline(code, stock_industry.get(code, ''))
    rendered = f"  {code} ${quote['price']:.2f} {quote['chg_pct']:+.2f}% {us_ref}"
    print(rendered)
```

## 💡 使用效果

每次启动监控时，你会看到：

```
🚀 启动
   ↓
📊 美股背景横幅 ← 了解全球态势
   ↓
📈 选股列表 + 美股标签 ← 选择对标美股强的股票
   ↓
👁️ 盘中监控 + 美股参考 ← 跟踪持仓同向性
   ↓
🎯 买卖点触发 + 美股确认 ← 美股弱就观望
```

相比原来：
- ❌ 看不到全球态势，容易逆向操作
- ✅ 能看到美股态势，选股、持仓、决策都有全球视角
