一、你现在的日常操作（真的只有一条命令）
每天早上开机，进入项目目录，执行：

每日总结：**邮件/企微已关闭**（`daily_summary_email_enabled: false`）。收盘后仍会写 `data/daily_summary.json` 作本地历史（`daily_summary_enabled: true`）；若连文件也不想生成，在 `config.json` 设 `daily_summary_enabled: false`。每周一 **09:30** 根据 `broker_xls/` 下中信证券交割单生成**上一交易周**券商周报（`weekly_report.py`），走 `notifications` 发邮件+企微。`data_health.full_outage_email_enabled` 默认亦为 **`true`**。不想推送时在 `config.json` 里改 `ops_automation.weekly_broker_report_email_enabled` / `daily_summary_email_enabled` 即可。

**券商交割单（命名：`交割单_YYYYMMDD_HHMMSS.xls`，如 `交割单_20260518_154126.xls`）**

```bash
cd /Users/haha/greatMan/stock-price-alert
# 将中信证券 PC 导出的交割单放入 broker_xls/
.venv/bin/python3 weekly_report.py -c config.json              # 周报
.venv/bin/python3 broker_period_report.py -c config.json --period monthly   # 月报
.venv/bin/python3 broker_period_report.py -c config.json --period h1        # 上半年
.venv/bin/python3 broker_period_report.py -c config.json --period h2          # 下半年
.venv/bin/python3 broker_period_report.py -c config.json --period annual      # 年报
# 只生成不发：加 --no-send；指定锚定日：--as-of 2026-05-16
```

**每周一 09:30 定时（cron，周末导出交割单到 broker_xls/ 即可）**

```bash
30 9 * * 1 cd /Users/haha/greatMan/stock-price-alert && .venv/bin/python3 weekly_report.py -c config.json >> logs/weekly_report.log 2>&1
```
