一、你现在的日常操作（真的只有一条命令）
每天早上开机，进入项目目录，执行：

```bash
cd /Users/haha/greatMan/stock-price-alert
# 先把中信证券「全历史」交割单覆盖到 broker_xls/（可昨晚或今早导出一次）
.venv/bin/python3 run_alert.py -c config.json --stdin-commands
```

`run_alert` 在 **`ops_automation.enabled: true`** 时会在每个交易日**自动**：
- **启动后一次**：用最新交割单回灌近 3 个交收日的盈亏 + 持仓到 `daily_summary_history`（`broker_sync_on_startup`）
- **15:10 收盘后**：写 daily_summary，并尝试回灌**当日**交割单（若文件里已有当日流水）

不必再单独跑 `broker_summary_sync`，除非要 `--all-days` 全量补历史。

每日总结邮件仍关闭；每周一 09:30 券商周报见下文。`data_health.full_outage_email_enabled` 默认 **`true`**。

**交割单 ↔ 系统学习闭环**（`config.json` 已默认打开）：

| 时段 | 动作 |
|------|------|
| 早上 `run_alert` 启动 | 交割单 → `daily_summary_history`（近 3 日盈亏+持仓）+ 信号后验采纳 |
| 收盘 15:10 | `daily_summary` → 当日交割单回灌 → `auto_tune_selector_filters`（叠券商盈亏）→ `auto_tune_accuracy` |
| 每周五收盘 | `operation_feedback` 按采纳信号表现调整 `min_score_by_strategy` |
