## 一、产品目标（当前实现）

- 面向 **macOS** 用户，定时拉取 **沪深 A 股** 最新价（数据源：东方财富公开 JSON 接口，非解析网页 HTML）。
- 支持为每只股票配置 **提醒模式**：
  - **`breach`（默认）**：现价 **≤ 下限** 或 **≥ 上限** 时弹系统通知。
  - **`band`**：现价落在 **[下限, 上限]** 闭区间内时提醒。
- 轮询间隔可配置，程序内 **最短 10 秒**（防止请求过于频繁）。
- 同一条件短时间内 **去重**（`.alert_state.json` 记录上次触发签名）。

用户当前关注的三只股票（已写入 `config.json`）：

| 名称     | 代码   | 市场 |
|----------|--------|------|
| 盛屯矿业 | 600711 | sh   |
| 爱旭股份 | 600732 | sh   |
| 立新能源 | 001258 | sz   |

当前未设 `alert_below` / `alert_above`，仅 **终端打印现价**，不弹通知。

## 三、配置 JSON 要点（摘要）

- **`poll_interval_seconds`**：轮询间隔；实际 `max(10, 配置值)`。
- **`watchlist[]`**：`code`、`market`（`sh`/`sz`）、`name`、`enabled`、`alert_mode`、`alert_below`、`alert_above`、`note`。
- **`sources.eastmoney_ut`**：接口查询参数，一般沿用示例。

## 四、命令行参数（已实现）

| 参数 | 作用 |
|------|------|
| `-c / --config` | 指定配置文件路径 |
| `--interval SEC` | 覆盖轮询秒数（仍 ≥10） |
| `--once` | 只跑一轮（适合 cron） |
| `--no-notify` | 仅打印，不弹通知 |
| `--test-notify` | 测试系统通知 |

## 五、已知限制与风险（请豆包在优化方案里正视）

1. **行情性质**：第三方公开接口，延迟一般为秒级，**非交易所毫秒级**，仅供个人辅助；接口字段或限流策略可能变更。
2. **合规**：README 已声明不构成投资建议；若对外分发需自行评估表述与所在地法规。
3. **平台**：通知依赖 macOS；Linux/Windows 需替换通知实现。
4. **「仅关注不设阈值」**：当前实现为上下限皆 `null` 时**只打印不弹窗**；若希望「任何价位变化都提醒」需新增逻辑（未实现）。
5. **依赖**：仅 `requests`；Python 3.10+ 语法（`str | None`）。
