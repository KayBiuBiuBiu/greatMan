# 系统优化项进展（与实现说明）

本文档对应「效果闭环 / 动态参数 / 分钟 K / 可观测性 / 板块缓存 / 概率形态」六条线的**目标、完成度与落地位置**。代码变更以仓库内实际文件为准。

---

## 1. 效果闭环（复盘）

| 项目 | 说明 |
|------|------|
| **目标** | 从 JSONL 中结构化事件 `watch_strategy_buy_filtered` 出发，统计拦截发生后未来 N 个交易日收益，避免凭感觉评估过滤。 |
| **落地** | `buy_filter_digest.py` + `scripts/analyze_buy_filter_outcomes.py`；**周五收盘后**由 `ops_automation`（`after_close_hhmm` 之后）自动 `send_email_alert` → 按 `notifications.remote_channel` 发 **邮件 + 企微**。 |
| **用法** | 自动：`ops_automation.friday_buy_filter_digest_enabled`（默认 true）。手动：`python scripts/analyze_buy_filter_outcomes.py --jsonl logs/run_alert.jsonl --forward-days 5`。需 `logging.enabled` 与东财日 K。 |
| **完成度** | **中高**（脚本 + 周五自动投递 + 状态去重 `__ops_buy_filter_digest_week__`）。 |

## 2. 动态 / 分环境参数（买入过滤）

| 项目 | 说明 |
|------|------|
| **目标** | 在 `dynamic_adaptive` 三档情绪下，覆盖 `strategy_buy_filter` 与 `sector_buy_cross_check` 的阈值。 |
| **落地** | `strategy_buy_filter_resolve.py`；`merge_full_config` 合并 `adaptive_by_mood`；每轮轮询设置 `cfg["_runtime_effective_strategy_buy_filter"]`。 |
| **配置** | `strategy_buy_filter.adaptive_by_mood.enabled` 与 `strong_bull` / `range` / `weak_bear` 下可选字段（与顶层 `strategy_buy_filter` 同名字段，深层合并 `sector_buy_cross_check`）。 |
| **完成度** | **中高**（运行时覆盖已接通）；参数具体取值需你按回测微调。 |

## 3. 特征与目标周期（分钟 K）

| 项目 | 说明 |
|------|------|
| **目标** | 有节制拉取**当日 1 分钟 K**（东财 `klt=1`），补充形态信息，默认关闭控制流量。 |
| **落地** | `quote_eastmoney.py`：`get_stock_minute_kline_summary_today`；`performance.fetch_minute_kline_today` + `minute_kline_max_bars`；`pack["minute_kline"]`。 |
| **完成度** | **中**（摘要进包；策略侧尚未强制消费该字段，可按需接线）。 |

## 4. 性能与可观测性

| 项目 | 说明 |
|------|------|
| **目标** | 轮询各阶段耗时可分解，便于对比「改前/改后」与定位变慢环节。 |
| **落地** | `performance.log_poll_segment_ms: true` 时：控制台一行摘要 + JSONL `event=poll_round_timing` 的 `metrics.seg_ms`；`--max-poll-rounds N` 便于固定跑 N 轮。 |
| **完成度** | **中**（分段覆盖指数/Hub/批量报价/拉包/处理 watch；未拆到单票级）。 |
