## 🎯 核心问题

当前买入规则有多个硬编码参数，但从未优化过：

```python
# quant_core/short_term_strategy.py - 第 84 行
rsi_oversold = rsi.iloc[-1] < 35           # ← 为什么是 35？

# 第 97 行
volume_surge = volume_ratio > 1.5           # ← 为什么是 1.5？

# 第 109 行
price_not_too_high = price_today < ma20 * 1.1  # ← 为什么是 1.1？
```

**问题**：这些参数是估计值，没有基于数据验证，可能不是最优的。

---

## 💡 优化思路

### 思路 1：快速分析（推荐先做）

使用脚本 `param_optimization_analysis.py` 快速分析历史picks：

```bash
# 快速测试（18 个参数组合）
python3 param_optimization_analysis.py -c config.json --quick-test

# 完整搜索（~400 个参数组合）
python3 param_optimization_analysis.py -c config.json
```

**工作原理**：
1. 加载所有历史picks文件（如 `data/picks_history/*.json`）
2. 对每只推荐的股票，查询 10 天后的价格
3. 计算收益率，判断是否成功（收益 ≥ 3%）
4. 遍历所有参数组合，统计胜率

**输出**：
- 分析 141 只股票（快速）
- 显示 Top 10 最优参数组合
- 与当前参数对比

**局限**：
- 当前不做进场信号过滤（简化版）
- 所有参数组合看到相同的股票集合

---

### 思路 2：完整回放（精确，但慢）

使用脚本 `param_optimize_backtest.py` 完整回放历史信号：

```bash
python3 param_optimize_backtest.py -c config.json --quick-test
```

**工作原理**：
1. 遍历每个参数组合
2. 对每个历史pick_date和stock_code：
   - 加载 K线数据
   - 用**该参数组合**重新计算进场信号
   - 如果满足进场，计算未来收益
3. 统计胜率

**优点**：
- 精确反映参数的真实效果
- 考虑了真实的进场信号过滤

**缺点**：
- 计算量大（每个参数组合需要 ~1000 次信号计算）
- 对于 400 个组合需要 30-60 分钟

## 💬 常见问题

### Q: 为什么快速分析和完整回放的结果可能不同？

**A**: 快速分析使用所有历史picks的结果，不过滤。完整回放根据每个参数组合，重新计算进场信号，所以每个参数组合看到的股票集合可能不同。完整回放更精确。

### Q: 搜索空间太大了，怎么加速？

**A**:
- 使用 `--quick-test` 先快速筛选有前景的参数范围
- 然后手工缩小搜索空间再做完整搜索
- 例如，如果快速测试发现 RSI 在 25-35 范围最好，就只搜索那个范围

### Q: 能否优化多个参数同时？

**A**: 当前支持 3 个参数（RSI, 成交量, 价格）的网格搜索。后续可以扩展到：
- 均线周期（目前固定 5/10）
- 时间持仓（目前固定 10 天）
- 止损/止盈参数

### Q: 优化后的参数多久需要更新一次？

**A**: 建议：
- 每周检查一次最新 picks 的表现
- 每月运行一次完整优化
- 如果市场环境改变（牛市→熊市），立即重新优化

## 📞 技术细节

### 进场信号的 4 个条件

```
1. 均线金叉: ma5 > ma10 (前一天 ≤)
2. RSI 超卖: RSI < rsi_threshold
3. 成交量突增: volume > volume_ratio × avg_volume_5d
4. 价格合理: price < ma20 × price_limit
```

### 成功标准

```
success = (未来10日最高价 - 买入价) / 买入价 ≥ 3%
```

如果数据不足 10 天，用最后一条可用数据。
