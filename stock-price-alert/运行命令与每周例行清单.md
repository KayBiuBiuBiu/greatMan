# 运行命令与每周例行清单

这份文档用于两件事：
- 统一说明「每条常用命令是干什么的」；
- 固化「开盘前/盘中/收盘后/每周」的执行节奏，直接照单跑。

若你固定 **早上 9 点**启动 `run_alert.py`，需要「几点敲什么」的一页纸对照，见：**[每日时间与命令对照.md](./每日时间与命令对照.md)**。

优化项对照（样本门槛、自检、launchd、北向/流式延后等）：**[优化实施记录.md](./优化实施记录.md)**。

## 一键自动（你提的场景）

如果你希望只执行一条命令：

- `python run_alert.py -c config.json`

并让系统自动完成：
- 每个交易日开盘前：同步日 K、计算指标、盘前选股；
- 每个交易日收盘后：回测 + 自动调参；
- 每周五收盘后：自动训练 ML 模型；

请在 `config.json` 打开 `ops_automation.enabled`：

```json
"ops_automation": {
  "enabled": true,
  "preopen_enabled": true,
  "preopen_cutoff_hhmm": "09:20",
  "after_close_enabled": true,
  "after_close_hhmm": "15:10",
  "friday_weekly_enabled": true,
  "backtest_since_days": 7,
  "auto_tune_apply": false,
  "auto_tune_email": true,
  "ml_train_weekly": true,
  "ml_train_days": 180,
  "ml_train_min_samples": 50
}
```

说明：
- `auto_tune_apply=false` 表示收盘后只做 dry-run 建议，不直接改配置；
- 想让它自动改配置可设为 `true`；
- 周五 ML 训练输出模型：`data/ml_bearish_nb.json`。
- 邮件回执执行卖出（可选）见下方 `email_command_bot`。

如果你希望收到卖出信号邮件后，直接“回邮件执行”，再在 `config.json` 增加：

```json
"email_command_bot": {
  "enabled": true,
  "use_shared_mail_config": true,
  "poll_interval_sec": 45,
  "mark_seen": true
}
```

当 `use_shared_mail_config` 为 `true`（默认）时，**IMAP 登录账号与授权码直接复用** `mail_config.json`（或环境变量 `MAIL_*`）里发买卖提醒的那套：`sender` / `password`；`imap_server` 会按发件邮箱域名自动猜（如 QQ → `imap.qq.com`）。也可在 `mail_config.json` 里手写 `imap_server` / `imap_port` / `imap_folder` 覆盖。

若你坚持单独配 IMAP，把 `use_shared_mail_config` 设为 `false` 并填写 `imap_*` 与 `trusted_senders`：

```json
"email_command_bot": {
  "enabled": true,
  "use_shared_mail_config": false,
  "imap_server": "imap.qq.com",
  "imap_port": 993,
  "imap_username": "your_email@qq.com",
  "imap_password": "your_imap_auth_code",
  "imap_folder": "INBOX",
  "trusted_senders": ["your_email@qq.com"],
  "poll_interval_sec": 45,
  "mark_seen": true
}
```

回复格式支持（邮件主题或正文都行）：
- `600711编号卖出`
- `卖出600711`
- `sell 600711`
- `600711编号买入`
- `买入600711`
- `买入600711 300 10.25`（代码 股数 成本）
- `buy 600711 300 10.25`

系统会自动转成运行时命令：
- 卖出：`sell 600711`（暂停该标的监控，不删除 config 条目）
- 买入（无仓位）：`hold 600711`（仅加入监控池）
- 买入（含仓位成本）：`hold 600711 300 10.25`（写入持仓）

## 一、命令总览（用途版）

### 1) 监控主程序 `run_alert.py`

- `python run_alert.py`
  - 启动主监控（默认仅交易时段拉行情）。
- `python run_alert.py --once --no-notify`
  - 只跑一轮，打印结果，不发系统通知（排障首选）。
- `python run_alert.py --poll-when-closed`
  - 休市也持续轮询（用于压测/联调，不建议常开）。
- `python run_alert.py --test-notify`
  - 测试通知链路（本地通知/声音）。
- `python run_alert.py --scan`
  - 用全市场规则重筛，写入 `watchlist`。
- `python run_alert.py --scan --force-scan`
  - 忽略扫描周期限制，立即强制重筛。
- `python run_alert.py --daily-select`
  - 跑盘前多策略选股，输出 `daily_picks.json`。
- `python run_alert.py --daily-auto`
  - 一键：先盘前选股，再进入盘中监控。
- `python run_alert.py --backtest-code 600711`
  - 对单只股票执行 1/3/5 年策略回测。
- `python run_alert.py --check-bk`
  - 检查 `watchlist` 的趋势板块 BK 映射，不拉行情。

### 2) 日 K 同步与指标预计算

- `python sync_daily_klines.py -c config.json`
  - 增量同步日 K 到本地 SQLite（默认模式，建议日常用）。
- `python sync_daily_klines.py -c config.json --full`
  - 全量重拉日 K（耗时更长，修复数据时用）。
- `python compute_kline_indicators.py -c config.json`
  - 预计算并落库技术指标（MA/ATR/MACD 等），加速盘中评估。

### 3) 预警回测与自动调参闭环

- `python backtest_alerts.py -c config.json --since 2026-04-01 --json-out weekly.json`
  - 对 `alert_events` 做后验评估，输出命中率与收益统计。
- `python auto_tune_accuracy.py --dry-run --days 7 --config config.json`
  - 仅给出调参建议，不改配置。
- `python auto_tune_accuracy.py --days 7 --config config.json`
  - 按命中率自动微调参数并写回配置（会自动备份 `.bak`）。
- `python auto_tune_accuracy.py --days 7 --config config.json --email`
  - 调参后额外发送邮件通知（已配置邮件时生效）。

### 4) 机器学习（bearish 概率）

- `python ml_train.py -c config.json --days 180 --model-out data/ml_bearish_nb.json`
  - 用 `alert_events` 历史样本训练轻量分类器，输出下跌概率模型。
- `python run_alert.py -c config.json`
  - 当 `ml_filter.enabled=true` 时，盘中对趋势预警执行 ML 低概率抑制。

### 5) 量化 CLI（可选入口）

- `python quant_cli.py daily-select -c config.json`
  - 独立运行盘前选股。
- `python quant_cli.py backtest --code 600711 -c config.json`
  - 独立运行单票回测。

### 6) 配置与质量保障

- `python -m pytest -q`
  - 跑测试，确认近期改动没有破坏行为。
- `python email_test.py`
  - 检查邮件发送配置是否可用。

## 二、开盘前 / 盘中 / 收盘后：执行清单

## 开盘前（建议 08:45-09:20）

- 第 1 步：同步日 K（增量）
  - `python sync_daily_klines.py -c config.json`
- 第 2 步：预计算指标
  - `python compute_kline_indicators.py -c config.json`
- 第 3 步：盘前选股（可选）
  - `python run_alert.py --daily-select -c config.json`
- 第 4 步：快速自检一轮（不发通知）
  - `python run_alert.py --once --no-notify -c config.json`
- 第 5 步：启动正式监控
  - `python run_alert.py -c config.json`

## 盘中（交易时段）

- 保持 `run_alert.py` 持续运行；
- 若怀疑异常（噪音突然增多/无行情），先另开终端做无通知检查：
  - `python run_alert.py --once --no-notify -c config.json`
- 仅调试场景才用：
  - `python run_alert.py --poll-when-closed -c config.json`

## 收盘后（建议 15:10 以后）

- 先补算预警回测（当天起算）
  - `python backtest_alerts.py -c config.json --since 2026-01-01 --json-out weekly.json`
- 再看是否自动调参（先 dry-run）
  - `python auto_tune_accuracy.py --dry-run --days 7 --config config.json`
- 若建议合理再正式执行
  - `python auto_tune_accuracy.py --days 7 --config config.json --email`

## 三、每周固定节奏（建议）

## 周一开盘前（重点）

- `python sync_daily_klines.py -c config.json`
- `python compute_kline_indicators.py -c config.json`
- `python run_alert.py --daily-select -c config.json`
- `python run_alert.py --check-bk -c config.json`
- `python run_alert.py --once --no-notify -c config.json`
- 最后启动：`python run_alert.py -c config.json`

## 周五收盘后 / 周末复盘（重点）

- 回测周报：
  - `python backtest_alerts.py -c config.json --since 2026-04-01 --json-out weekly.json`
- 自动调参（先预览再落地）：
  - `python auto_tune_accuracy.py --dry-run --days 7 --config config.json`
  - `python auto_tune_accuracy.py --days 7 --config config.json --email`
- 变更后验证：
  - `python run_alert.py --once --no-notify -c config.json`
  - `python -m pytest -q`

## 四、回滚与应急

- 自动调参后想回滚：
  - `cp config.json.bak config.json`
- 配置改坏启动失败时：
  - 先回滚，再执行 `python run_alert.py --once --no-notify -c config.json` 验证。
- 若邮件通知没发出：
  - 先跑 `python email_test.py` 检查邮件配置。

## 五、建议的最小自动化（可选）

- 每个交易日开盘前（同步 + 指标）：
  - `sync_daily_klines.py` + `compute_kline_indicators.py`
- 每周一次（回测 + 自动调参）：
  - `backtest_alerts.py` + `auto_tune_accuracy.py --dry-run`
  - 人工确认后再执行非 dry-run。
