## ❌ vs ✅ 策略对比

### 旧策略（固定止盈）
```

  ↓
```

**问题**：太死板，可能错过更大涨幅

### 新策略（动态目标价）
```
买入 12.50
  ↓
分析预测这只股会涨多少
  • 技术位：20日线 13.13 (涨 5%)
  • 历史：平均 4% 涨幅
  • 综合预测：涨 4.5% 到 13.07
  ↓
设定目标价：13.07 × 95% = 12.42 (卖点)
  ↓
- 12.36 (亏 2%)：止损卖 ✓ 保护本金
- 12.67 (涨 1%)：继续持仓，还没到目标
- 13.06 (涨 4.5%)：接近目标，卖出 ✓ 实现预测收益
- 14.38 (涨 15%)：如果快速突破，继续持仓 ✓ 可能超额收益
- 10天未出：无条件卖 ✓ 时间到期
```

**优势**：
- ✅ 根据预测灵活卖，不死板
- ✅ 有合理的目标价，可以追踪进度
- ✅ 如果强势突破，可以继续持仓
- ✅ 保留止损保护，防止大亏

## 📊 怎么预测这只股会涨多少？

### 方法 1：技术位阻力位（立即可用）

```python
查找关键的技术位置:
  • 20日均线：短期阻力
  • 50日均线：中期阻力
  • 20日最高价：心理阻力

例如:
  当前价: 12.50
  20日线: 13.20  ← 明确的阻力位
  50日线: 13.50  ← 更远的阻力位
  
预测: 可能涨到 13.20 (涨 5.6%)

优点: 简单直观，基于图表
缺点: 需要一定的技术分析能力
```

### 方法 2：历史平均涨幅（数据驱动）

```python
统计这只股过去 30 天的平均日涨幅:
  • 平均日涨幅: +0.5%
  • 10日期望涨幅: 0.5% × 10 = 5%
  
例如:
  当前价: 12.50
  预期10日涨幅: 5%
  预测目标: 12.50 × 1.05 = 13.13
  
优点: 数据支撑，客观
缺点: 假设历史会重复
```

### 方法 3：混合预测（推荐）

```python
结合技术位 + 历史平均:

方案 A:
  技术位预测: 13.20 (涨 5.6%)
  历史平均: 13.13 (涨 5%)
  综合: (13.20 + 13.13) / 2 = 13.17 (涨 5.3%)

方案 B:
  取保守值: min(13.20, 13.13) = 13.13
  确保容易达到

推荐: 用方案 A (取平均), 这样既有技术支撑又有数据验证
```

### 方法 4：ML 模型（后续优化）

```python
输入: [开盘、最高、最低、收盘、成交量、RSI、均线]
      
输出: {
  "3day_target": 12.95,   # 3日预测
  "5day_target": 13.08,   # 5日预测
  "7day_target": 13.20,   # 7日预测
  "10day_target": 13.40,  # 10日预测
}

这个需要大量历史数据训练
但一旦建立，预测会很精准 (70%+ 准确度)
```

## 🎯 新的交易流程

### 步骤 1：确认进场信号

```
和之前一样，需要满足 4 个条件:
  ✅ 5日均线金叉 10日均线
  ✅ RSI < 35
  ✅ 成交量突增
  ✅ 价格合理
```

### 步骤 2：进场后预测涨幅

```
进场的第一时间:
  1️⃣ 查看关键技术位 (20日线、50日线)
  2️⃣ 查看历史平均涨幅
  3️⃣ 综合两个预测
  4️⃣ 设定目标价
  
例如:
  买入价: 12.50
  技术位: 13.20
  历史平均: 13.13
  目标价: (13.20 + 13.13) / 2 = 13.17 ✓
```

### 步骤 3：设定卖点

```
根据预测目标设定卖点:
  目标价: 13.17
  推荐卖点: 13.17 × 95% = 12.51 (保留 5% 容错)
  止损价: 12.50 × 98% = 12.25 (-2% 止损)
  
记录这些价格，监控股价走势
```

### 步骤 4：持仓管理

```
每天监控:
  ✅ 如果价格 < 12.25 → 止损卖出
  ✅ 如果价格 ≥ 12.51 → 达到目标，考虑卖出
  ✅ 如果价格在 12.25-12.51 之间 → 继续持仓
  ✅ 如果持仓 10 天 → 无条件卖出
  ✅ 如果快速上涨超过预测 → 继续持仓看能否更高
```

## 🔧 实现方式

### 代码使用

```python
from quant_core.dynamic_target_predictor import DynamicPriceTargetPredictor

# 1. 加载数据
df = load_df("600711", lookback=60)

# 2. 获取当前价
current_price = 12.50

# 3. 预测目标价
prediction = DynamicPriceTargetPredictor.predict_target_price_combined(df, current_price)

print(f"预测目标: {prediction['combined_target']:.2f}")
print(f"推荐卖价: {prediction['recommended_sell_price']:.2f}")
print(f"止损价: {prediction['stop_loss_price']:.2f}")

# 4. 在持仓过程中，每天检查是否应该卖出
should_sell, reason, metrics = DynamicPriceTargetPredictor.should_sell_by_target(
    entry_price=12.50,
    current_price=12.95,  # 当前价
    target_price=prediction['combined_target'],
    stop_loss_price=prediction['stop_loss_price'],
    days_held=3
)

if should_sell:
    print(f"卖出: {reason}")
else:
    print(f"继续持仓: {reason}")
```

## 🎓 为什么这个方案更好？

### 1. 基于预测，不是固定规则
```
固定: +5% 就卖，不管股票能涨多少
动态: 预测能涨 10%，就等到接近 10% 时卖
```

### 2. 有明确的目标，可以追踪进度
```
你买了以后就知道:
  • 目标价是多少
  • 目前涨了多少
  • 还需要涨多少

而不是盲目等待
```

### 3. 如果强势突破，可以继续持仓
```
预测 5% 但快速涨 8% → 继续持仓
预测 5% 但怎么涨不动 → 放弃等待

灵活应对，不被死规则限制
```

### 4. 止损保护保持不变
```
虽然卖点变了，但止损还是 -2%
最坏的情况就是亏 2%，可控
```
