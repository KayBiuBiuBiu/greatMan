# 几点要干嘛（超简版）

先 **`cd` 进 `stock-price-alert` 目录**。下面时间按你 `config.json` 默认（盘前截止 **09:20**，收盘后 **15:10** 起）来写。

**前提（不写清楚会漏跑）：** `ops_automation.enabled` 已打开；**监控池里至少有一只股票**；`run_alert` **进程别在 15:10 前就关**。

---

## 周一～周四（每天都一样）

| 几点 | 你要干嘛 |
|------|----------|
| **～9:00** | 开机，进项目文件夹 |
| **约 9:00** | 执行：`python run_alert.py -c config.json`，然后**别关**，挂着到下午三点多以后 |
| **9:00～9:20** | **你不用敲命令**。程序自动：同步日 K → 算指标 → 盘前选股 |
| **9:30～15:00** | **你不用敲命令**。正常预警轮询 |
| **15:10 以后** | **你不用敲命令**。程序自动：回测、调参（发邮件等，看你配置） |

**若你下午必须关机**：晚上在项目目录补跑下面两条（日期里的 `YYYY-MM-DD` 改成「大约一周前」的交易日）：

```bash
python backtest_alerts.py -c config.json --since YYYY-MM-DD --json-out weekly.json
python auto_tune_accuracy.py --days 7 --config config.json --dry-run --email
```

---

## 周五

| 几点 | 你要干嘛 |
|------|----------|
| **～9:00、约 9:00、9:00～15:00** | **和周一～周四完全相同**（还是那一条 `run_alert` 挂着） |
| **15:10 以后** | 先和平时一样自动：**回测 + 调参**；**再多一步**：若配置里周训练开着，程序会再自动跑 **`ml_train.py`**（更新 NB 模型） |

**若周五你也没挂着进程**：周五晚上在项目目录补一行：

```bash
python ml_train.py -c config.json
```

---

## 周六、周日

不用按交易日那套操心；`run_alert` 里的**日更自动化周末不跑**。你想看盘就自己开，不开也行。

---

## NB + 外部资金流（真打标 → 重训）

`config.json` 里请保持 **`ml_filter.external_flow_features_enabled": true`**、**`external_flow_days": 10`**（与当前 NB 特征维一致）；日常监控：

```bash
.venv/bin/python3 run_alert.py -c config.json
```

**定期**用 `alert_events` 里的真实走势回填 **`hit`**（把 `--since` 换成你的区间起点）：

```bash
.venv/bin/python3 backtest_alerts.py -c config.json --since 2026-04-01
```

样本够（`hit` 为 0/1 且条数 ≥ `ml_train` 的 `--min-samples`，且两类都有）后全量重训：

```bash
.venv/bin/python3 ml_train.py -c config.json
```

**可选**：`ops_automation` 里 **`incremental_nb_after_close": true`**（及 `incremental_nb_min_samples`），收盘后用窗口内带 `hit` 的数据增量重训。

**验证**：看 `logs/run_alert.jsonl` 里 **`watch_trend_slip_detail`**：`ml_external_flow_snapshot` 应有 5 个数；**`ml_nb_full_dim`** 为 **NB 模型 JSON 的 `features` 长度**（开外部流时期望 **11**；若为 **6** 说明仍是旧 6 维模型，请用当前配置重新 `ml_train.py`）。另见 **`ml_nb_vector_dim`**（推理侧特征向量长度）。
