💡 关键发现

为什么完整场景改善这么大？

  缓存原理:
  • 每只股票评分: 需要 4个 lookback 参数 (60/250/750/1250 days)
  • 第1次: 60只 × 4个参数 = 240次 API 调用
  • 第2次: 240次都命中 LRU 缓存 = 0次 API 调用
  
  时间分解:
  • 第1次: API 调用时间 (45s) + 数据处理 (7.6s) = 52.6s
  • 第2次: 缓存快速返回 (0s) + 数据处理 (5.4s) = 5.4s
  • 差异: 47.2s 全部来自缓存击中
